2.3 发现的典型问题（按严重度排序，全部有据可查）

P1（严重）未初始化变量就被使用 —— 未定义行为

文件 7_循环_正序分解.c：

int num, ret;        // ret 没有初始化
...
ret = ret * 10 + digit;   // 用未初始化的 ret 参与运算，值是"随机垃圾"

文件 7_循环_猜数.c：

int number = rand() % 100 + 1;
int a;                     // a 没有初始化
while (a != number) {       // 第一次判断时 a 是垃圾值

这两个程序有时能跑对，有时是错的——这正是未定义行为最危险的地方。教程阶段二会专设一节讲"变量出生时必须给值"。

P2（严重）边界条件错误

7_循环_正序分解.c 中 while (num > 10) 应为 while (num >= 10)：当输入两位数（如 23）时，十位永远不会被分解，循环体内少了最后一次处理。边界差一个等号，结果差一类输入。

P3（隐患）用浮点函数做整数幂

7_循环_水仙花.c 用 (int)pow(d, n) 计算整数立方。pow 返回 double，pow(9,3) 在部分实现中可能是 728.9999…，强转后变 728，导致偶发漏判。整数幂应该用循环累乘。这是阶段二/阶段七会展开的"浮点精度"专题。

P4（规范）main 结尾缺 return 0;、变量命名随意

7_循环_素数求和.c、7_循环_猜数.c 结尾没有 return 0;（C99 起允许，但初学阶段建议显式写出，养成确定性习惯）；部分文件变量名 a/b/t/ret 混用，可读性偏弱。考核任务明确要求"代码书写以及变量定义规范，关键处加注释"——从现在起练习命名。

P5（缺失）从未见过：函数、数组、指针、结构体

整个 D 盘目录没有任何自定义函数、任何数组、任何指针、任何结构体。也就是说：任务三到考核所需的全部核心知识，目前是零基础。这是本学习计划的主战场。
