阶段一 练习题（环境与调试）先做后看答案

用法：先独立完成，再对照同目录 答案_参考.md 与 答案_*.c。 做完每题在打卡表记 1 分；错了记入错题本。

练习 1（基础 · 观察）制造并翻译四类错误

新建 err_lab.c（内容随意，一个 printf 即可），依次故意制造 4 种错误，每次记录： 报错原文 + 你的一句话"翻译"（它到底在说什么）+ 它属于流水线哪一步：

  1. 少分号：删掉 printf 行末的 ;
  2. 入口拼错：main 改成 mian
  3. 函数名拼错：printf 改成 print
  4. 未声明使用：在 main 里写 int a; a = b + 1;（b 从未声明）

练习 2（基础 · 纸上功夫）推演 02_bug_hunt.c

不运行程序，纸上推演输入 907 时的完整执行过程。 逐轮列表记录三个变量 num、digit、ret 的值（循环第一轮、第二轮、……直到循环结束），再预测打印内容。然后用实际运行验证。

练习 3（提高 · 思考）"反转"与"倒序"的区别

02_bug_hunt.c 中输入 120 时输出是 0 2 1 还是 1 2 0？ - 程序做的是"数字反转"（120→21，注意丢了什么）还是"倒序打印"？ - 两种需求各应该在什么环节处理末尾的 0？ - 用断点（F10）走一遍第二个 while，观察 ret 的变化并记录。

练习 4（提高 · 实操）给整个历史代码体检

把 -Wall -Wextra 加入 D:\Programing\C\.vscode\tasks.json 的 args， 重新编译你 D 盘全部 7_循环_*.c 文件： - 记录哪些文件出现 warning、警告原文是什么； - 选 2 个修掉（提示：7_循环_猜数.c 一定中奖）； - 把结果写入错题本（每条：文件名/警告原文/原因/修法）。

练习 5（挑战 · 防御性编程）输入合法性检查

修改 02_bug_hunt.c： 1. 输入 ≤ 0 时打印"输入非法"并退出（return 1）； 2. 思考并记录：用户输入字母 abc 时 scanf 返回什么？程序表现如何？ 3. （选做）搜索了解 while (getchar() != '\n'); 这行代码常被用来做什么？ 现在只需要把现象和这条线索记进错题本，阶段四正式学会它。
