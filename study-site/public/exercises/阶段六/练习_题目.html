阶段六 练习题（结构体、联合与枚举）先做后看答案

纪律：先做后看答案；纸上作业（练习 3）禁止跳过——sizeof 与对齐直觉是阶段七的地基。 每题训练点见教程 §11；错题逐条记入你自己的错题记录。 所有程序要求 -Wall -Wextra -std=c99 零警告。

练习 1（基础）两点距离函数

  1. 定义 struct Point { double x; double y; };；
  2. 写 double distance(struct Point a, struct Point b)：返回两点间距离（√((x₁-x₂)² + (y₁-y₂)²)，sqrt 在 <math.h>）；
  3. main 测试三组：(0,0)-(3,4) 应得 5.0；(1,1)-(1,1) 应得 0.0；(-1,-1)-(2,3) 应得 5.0；
  4. 想一想：这里传值合理吗？（struct Point 才 16 字节——合理；换成 1000 字节的大结构体呢？）

练习 2（基础）矩形结构体：面积与包含判断

定义 struct Rect { double x; double y; double w; double h; };（x,y 是左下角坐标，w,h 是宽和高）：

  1. 写 double area(struct Rect r)：返回面积；
  2. 写 int contains(struct Rect r, struct Point p)：点 p 在矩形内（含边界）返回 1，否则返回 0（struct Point 复用练习 1 的定义）；
  3. main 用 struct Rect r = {0, 0, 10, 5}; 测试：点 (5, 2) 在内、点 (10, 5) 在边界上（算在内）、点 (11, 2) 在外。

练习 3（基础 · 纸上作业，必须做）sizeof 与内存布局推演

先纸上推演，再上机用 sizeof 验证（验证代码自己写，答案文件只给推演结论）：

struct A { char c; int n; };
struct B { int n; char c; };
struct C { char a; char b; int n; };
struct D { double d; char c; };
  1. 不看答案，先写出你预测的 sizeof 各是多少；
  2. 画出 struct A 的内存布局图（标出每个成员从第几字节开始、哪里是填充 padding）；
  3. 上机验证：四个 sizeof 的真实值是多少？哪个预测错了？
  4. 一句话回答：为什么成员顺序不同（A vs B），sizeof 却可能相同、布局却不同？
  5. （附加思考）怎样排列成员能省内存？（教程 §7 有提示）

练习 4（提高）日期比较函数

定义 struct Date { int year; int month; int day; };：

  1. 写 int date_cmp(struct Date a, struct Date b)：a 早于 b 返回 -1，同日返回 0，a 晚于 b 返回 1（按年→月→日字典序比较）；
  2. 不许把日期换算成总天数再比——逐成员比较才是本题的训练点；
  3. main 至少测四组：同年同月不同日、同年不同月、不同年、完全相同；
  4. 附加：写 struct Date earliest(const struct Date arr[], int n)，用 date_cmp 找出数组里最早的一天（擂台法复用）。

练习 5（提高）图书数组按年份排序

复用教程 03 的 struct Book（书名/年份/定价）：

  1. 写 void sort_by_year(struct Book shelf[], int n)：冒泡排序，按年份从小到大；
  2. 交换相邻两本书时用结构体整体赋值（§4 值语义：临时变量倒手和 int 交换一模一样）；
  3. main 初始化 4~5 本乱序的书，排序前后各打印一遍；
  4. 想一想：冒泡交换的是整个结构体（每本几十字节），如果书很大很多会怎样？（预告：阶段九有更省的办法——排序指针数组。）

练习 6（提高）union 字节观察：先预测再验证

union IntViewer {
    int          whole;
    unsigned char bytes[4];
};
  1. 先纸上预测：v.whole = 0x00FF00FF; 后，v.bytes[0..3] 各是多少（这台机器是小端）？v.whole = 256; 呢？
  2. 写程序验证你的预测，逐字节打印 %02X；
  3. 附加实验：v.whole = -1; 时四个字节各是什么？（看不懂没关系，记下来——阶段七讲补码时回收这个伏笔。）
  4. 再声明 union { short s; unsigned char b[2]; }，预测并验证 s = 0x0102; 的字节顺序。

练习 7（挑战）魔法数字菜单重构为 enum 版

下面是一个用魔法数字写的迷你菜单（能跑，但难看难维护）：

int choice = -1;
while (choice != 0) {
    printf("0 退出  1 千米→英里  2 摄氏→华氏  3 千克→磅\n");
    scanf("%d", &choice);
    if (choice == 1)      { /* 读入 km，乘 0.6214 输出 */ }
    else if (choice == 2) { /* 读入 C，×1.8+32 输出 */ }
    else if (choice == 3) { /* 读入 kg，乘 2.2046 输出 */ }
    else if (choice != 0) { printf("无效选项\n"); }
}

重构要求： 1. 定义 enum Menu { MENU_EXIT = 0, MENU_KM2MI, MENU_C2F, MENU_KG2LB };，菜单打印与分支全部改用枚举名； 2. if-else 链改成 switch； 3. 每个换算封装成独立函数（阶段三功夫）； 4. scanf 检查返回值（阶段二纪律：读失败要处理，不能拿着垃圾值继续）。

  • 练习 4、5 是任务四/任务六的能力积木（函数组织、整体赋值交换），优先级高；
