答案参考（文字题）：段码位序与扫描时序推演参考答案

对应练习 3。接法：4 位共阴数码管，段码 1 = 亮；位选低电平有效，DIG0~DIG3 从左到右。 目标内容：4207；每位窗口 2ms；位序 P0.7=dp P0.6=g P0.5=f P0.4=e P0.3=d P0.2=c P0.1=b P0.0=a。 所有结论都依赖原理图；换共阳屏或位选反相时，段码和有效电平要重算。

A 部分：段码位序表

A.1 段、位号与四个数字的 0/1

段名 位号 4 2 0 7
a P0.0 0 1 1 1
b P0.1 1 1 1 1
c P0.2 1 0 1 1
d P0.3 0 1 1 0
e P0.4 0 1 1 0
f P0.5 1 0 1 0
g P0.6 1 1 0 0
dp P0.7 0 0 0 0

从下往上按 dp g f e d c b a 读，就是 8 位二进制：

数字 点亮的段 共阴二进制 共阴码 共阳二进制（逐位取反） 共阳码
4 b c f g 0110 0110 0x66 1001 1001 0x99
2 a b d e g 0101 1011 0x5B 1010 0100 0xA4
0 a b c d e f 0011 1111 0x3F 1100 0000 0xC0
7 a b c 0000 0111 0x07 1111 1000 0xF8

复核方法：把十进制的段码展开成二进制，再按 bit0=a、bit1=b……bit6=g、bit7=dp 对回段名。 例如 0x66 = 0110 0110，bit6/5/2/1 为 1，对应 g、f、c、b，正好是 4。

B 部分：一个完整扫描周期的时序推演

B.1 每个窗口内部的三段

为了把消隐讲清楚，把每位 2ms 的窗口拆成三段：

子阶段 时长（假设） 动作
消隐 0~10us SEG = 0x00，8 段全灭，旧位不再显示旧数字
换位 + 送码 10~15us 写 DIG 选中新位，再写 SEG = 新段码
保持 15us~2000us 保持这一位的段码，让它在 2ms 窗口里亮够时间

关键顺序只有一个：先让 SEG 灭，再改 DIG，最后送新 SEG。这 5us 的换位动作相对 2ms 可以忽略，但不能省掉。

B.2 四行完整时序表

窗口 绝对时间 消隐时刻与动作 选中的 DIG 送出的 SEG（共阴） 亮的位与数字 保持
1 0.000~2.000ms 0.000ms 写 SEG=0x00；0.010ms 写 DIG=0xFE；0.015ms 写 SEG=0x66 0xFE 0x66 第 1 位：4 约 1.985ms
2 2.000~4.000ms 2.000ms 写 SEG=0x00；2.010ms 写 DIG=0xFD；2.015ms 写 SEG=0x5B 0xFD 0x5B 第 2 位：2 约 1.985ms
3 4.000~6.000ms 4.000ms 写 SEG=0x00；4.010ms 写 DIG=0xFB；4.015ms 写 SEG=0x3F 0xFB 0x3F 第 3 位：0 约 1.985ms
4 6.000~8.000ms 6.000ms 写 SEG=0x00；6.010ms 写 DIG=0xF7；6.015ms 写 SEG=0x07 0xF7 0x07 第 4 位：7 约 1.985ms

一整帧结束时回到 t=8.000ms，再从第 1 位开始，形成无限循环。

B.3 三个时间指标

  • 一帧 = 4 位 × 2ms = 8ms；
  • 刷新率 = 1000ms ÷ 8ms = 125Hz；
  • 每位占空比 = 2ms ÷ 8ms = 25%（严格算上每窗口约 10us 消隐和 5us 换位开销，是 24.8%，差别可忽略）。

所以任何瞬间只有一位导通，但人眼以 125Hz 看到的是四位同时亮；亮度约为「一直亮」的四分之一。 若把每位保持改成 3ms，则一帧 12ms、刷新率约 83.3Hz，占空比仍是 25%——刷新率变了，占空比没变。

C 部分：消隐时机判断

C.1 不消隐时的鬼影

假设第 1 位还显示 4（SEG=0x66），程序直接改 DIG 到第 2 位，然后才送 2 的段码 0x5B：

时间：        1.995ms      2.000ms       2.005ms
DIG：         0xFE  ---------> 0xFD
SEG：         0x66  ----------------------> 0x5B
实际显示：    第1位 4       第2位先亮 4    第2位 2
                            ↑ 鬼影窗口约 5us

第 2 位在 5us 里收到了上一位的段码 0x66，它的 b、c、f、g 段亮，看起来就是 4。 如果 SEG 更新得再慢一点，鬼影会持续更久；如果 5us 恰好被下一帧的人眼积分平均掉， 可能只是「有一点虚影」，但绝不能因此省掉消隐。

C.2 四种顺序对错

顺序 判断 理由
① SEG=0 → DIG=新位 → SEG=新码 正确 改 DIG 时 SEG 已经是 0，新旧位都不会显示旧码
② DIG=新位 → SEG=0 → SEG=新码 错误 改 DIG 的瞬间旧码仍在，新位先闪旧数字，之后再灭一下
③ SEG=新码 → DIG=新位 错误 DIG 还是旧位时新码已经上口，旧位先显示新数字，再换位
④ DIG=新位 → SEG=新码 错误 旧码在换位瞬间仍有效，完整地落到新位上，形成持续数微秒的鬼影

判断口诀：换 DIG 之前，SEG 必须是灭的；SEG 变新码之前，DIG 必须已经是新位。 第 ① 种顺序同时满足这两条。把 SEG=0 放在上一窗口末尾，效果等价。

C.3 换成 L 3 8 .

四个位置分别显示 L、3、8、.（最后一位只显示小数点）：

  • 3 仍是 0x4F，8 仍是 0x7F，不变；
  • L 点亮 d、e、f 三段，共阴码 = 0x38（0011 1000），共阳码 = 0xC7；
  • 最后一位只亮 dp：共阴码 = 0x80，共阳码 = 0x7F。

如果题意是「最后一位显示带小数点的 8」，则最后一位是 0x7F | 0x80 = 0xFF； 共阳码为 0x00。两种理解只差最后一位，前三位不受影响。

D 部分：接法反思

D.1 为什么共阳码是逐位取反，不是 +1

共阴和共阳的差别，是同一段「亮」时引脚应该输出 1 还是 0。这是 8 个独立位的极性翻转， 位与位之间没有进位关系，所以只能用按位取反 ~，不能做算术加一。

反例：数字 0 的共阴码是 0x3F（0011 1111）。

  • 0x3F + 1 = 0x40（0100 0000），只亮 g 段，看起来像一条横杠，不是 0；
  • 0x3F 取反再加 1 = 0xC0 + 1 = 0xC1，仍然不是正确的共阳码 0xC0。

D.2 位选经过 PNP 反相还能不能说 0xFE 选中第 0 位

不能直接下结论。0xFE 只说明「P2 的 bit0 是 0、其余是 1」，而这一位最终让哪一位数码管 导通，还取决于它是直接接公共端、经 NPN 灌电流、经 PNP 拉电流，还是经过 74HC138 等译码器。 同样一个 0xFE，在低电平选通的板上选第 0 位，在反相驱动的板上可能一位都不选，甚至选中别的位。 必须拿原理图确认有效电平，再决定位选码。

D.3 能不能直接背「0x3F 就是数字 0」

不能脱离接法和位序。0x3F 只有在「共阴、bit0=a、bit7=dp」这套约定下才是数字 0； 换成共阳，0x3F 会让 g、dp 等段亮，根本不是 0。段码表可以背，但必须同时背它的前提： 共阴还是共阳、a 接哪一位、dp 在哪一位。 这三个条件一变，表就要重算。

本题自检清单

  • 4 个数字的段码能由 a~g 逐位推出，不靠抄表；
  • 4207 的共阴码是 66、5B、3F、07，共阳码是 99、A4、C0、F8；
  • 完整帧 8ms、125Hz、25% 占空比三个数一致；
  • 能指出鬼影发生在「DIG 已换、SEG 未换」的窗口；
  • 能说清消隐值在共阳屏上应改成 0xFF；
  • 知道 0x3F = 0 依赖共阴、位序、接线三个前提，不是绝对真理。
