阶段四 练习题（数组与字符串）先做后看答案

纪律：先做后看答案；纸上作业（练习 3）禁止跳过——'\0' 认知是任务五与考核的地基。 每题训练点见教程 §11；错题逐条记入你自己的错题记录。

练习 1（基础）数组逆置函数

  1. 写 void reverse(int arr[], int n)：把前 n 个元素就地逆置（不许开第二个数组）；
  2. 写 void print_array(const int arr[], int n)；
  3. main：{1,2,3,4,5,6,7} 逆置后打印；再逆置一次，应回到原样（自检）；
  4. 边界自测：n=1（单元素）、n=0（空）。

练习 2（基础）成绩统计（double 数组）

一组成绩：{78.5, 92.0, 66.5, 88.0, 92.0, 59.5}。 1. 写 double average(const double arr[], int n)； 2. 写 int max_index(const double arr[], int n)（返回最高分的下标，并列保留先出现者）； 3. main 输出：平均分（%.2f）、最高分及其下标。

练习 3（基础 · 纸上作业，必须做）内存图与两个"长度"

对 char s[] = "Hi!\n";： 1. 画出完整内存图（逐格写出下标、字符、终止符；注意 \n 是一个字符）； 2. sizeof(s) = ？strlen(s) = ？my_strlen(s) = ？ 3. char t[3] = "abc"; 这样写会发生什么？（提示：3 格装不下 4 格的内容， 编译器会警告/报错——亲手试一次，把警告原文记下来） 4. 一句话回答：为什么"装 50 个字符的字符串，数组至少要 51 格"？

练习 4（提高）十进制转二进制

输入一个非负整数（≤ 1000000），打印二进制。 - 方法：除 2 取余，余数逐个存进 int 数组，最后倒序输出； - 边界：0 的二进制就是 0（单独处理，否则你的循环一次都不跑）； - 示例：13 → 1101（13/2=6 余1 → 6/2=3 余0 → 3/2=1 余1 → 1/2=0 余1）； - 这题的"数组带出数据"模式（返回位数 + 数组装余数）与阶段三的 num_to_digits 同构， 也与任务七的类型转换地基相连。

练习 5（提高）凯撒密码加密器

输入一行文字（fgets 读入），输出加密版：每个字母在字母表内 +3（循环：x→a, X→A）， 非字母字符原样保留。例：Attack at dawn! → Dwwdfn dw gdzq! - 大小写分别处理（保持原大小写）； - 循环进位：'x'+3 应得 'a' 而不是 '{'（提示：减去 'a' 后模 26 再加回）； - 输入长度上限 100。

练习 6（提高）字符分类器

用 fgets 读入一行（≤200 字符），统计并输出： - 大写字母、小写字母、数字、空格、其他字符 各多少个； - 5 个计数器分别初始化为 0； - 注意先清理 fgets 读入的 \n 再统计（决定 \n 算不算"其他"——注释里写明你的选择）。

练习 7（挑战）单词计数器

读入一行英文（≤200 字符），输出： 1. 单词个数（连续的非空格字符算一个单词，标点归属它贴着的单词，如 don't 算 1 个）； 2. 最长单词的长度； 3. （选做）打印出那个最长的单词。 提示：遍历时做"状态切换"——当前字符是字母（非空格）且上一字符是空格（或行首）， 就是新单词的开始。"状态计数"思想与连续模式计数是一对孪生兄弟。
