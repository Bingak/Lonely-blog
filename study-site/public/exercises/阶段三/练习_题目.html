阶段三 练习题（函数）先做后看答案

纪律：先做后看答案；纸上推演题（练习 3）禁止跳过——它是阶段五指针的地基。 每题预期训练点见教程 §11；错题逐条记入你自己的错题记录。

练习 1（基础）max3 与温度转换

  1. 写函数 int max3(int a, int b, int c) 返回三个整数的最大值；
  2. 写函数 double c_to_f(double celsius) 把摄氏度转华氏度（×9/5 + 32）；
  3. main 里各至少调用 2 次（含负数、相等值等不同情况），printf 结果保留 4 位小数。 要求：两个函数都要有原型声明。

练习 2（基础）闰年函数（注意 1900 陷阱）

  1. 写函数 int is_leap_year(int year)：闰年返回 1，平年返回 0。 规则：能被 4 整除且不能被 100 整除，或能被 400 整除。
  2. main 打印 1896~1912 与 2000 的判定结果。
  3. 思考（写进代码注释）：1900 能被 4 整除，为什么不是闰年？ 你的函数输入 1900 输出的是几？输入 2000 呢？

练习 3（基础 · 纸上作业，必须做）复印件定理推演

对照 code\阶段三_函数\02_swap_fail.c： 1. 画内存图：main 的 x、y 两格（标地址、值 1、2）， swap_wrong 的 a、b、t 三格（标地址、三轮交换中值的变化）； 2. 用断点 F11 实际走一遍，把 VARIABLES 面板与你的手画图逐项核对； 3. 回答：为什么 [调用后] x=1 y=2？"复印件"具体指哪几块内存？ 4. 一句话预言（不许查资料）：如果你能把 x 的"地址"也传进去， 函数有没有办法改到 x 的值？

练习 4（提高）位数与反转

  1. 写 int count_digits(int n)（对照示例 04 里已有的版本，不许抄，自己重写）；
  2. 写 int reverse_number(int n) 返回 n 的数字反转（如 12345 → 54321；注意负数与末尾 0 的行为，注释里写清你的定义）；
  3. main 验证：12345、100、7、-321 四组。

练习 5（提高）数组作参数（任务三直系训练）

  1. 写 void fill_squares(int arr[], int n)：把 arr 填成 1~n 的平方表；
  2. 写 int sum_array(const int arr[], int n)：返回数组前 n 项之和（const 表示只读）；
  3. main：定义 int data[10]，调用 fill_squares 后打印数组并求和；
  4. 思考：为什么 fill_squares 能改 main 里的数组、而阶段一的 swap_wrong 改不了 main 里的变量？（一句话，写进注释）

练习 6（提高）阶乘与溢出现场

  1. 写 int factorial_int(int n)：n 的阶乘，返回 int；
  2. main 打印 1!~15!；
  3. 找出 int 版本从第几项开始结果不可信（提示：int 上限 2147483647； 12! = 479001600 还在范围内，13! = 6227020800 已超出）；
  4. 再写 long long factorial_ll(int n)（用 %lld 打印）， 打印 18!~21!，看它又能撑到第几项；
  5. 思考（写进注释）：13! 在 int 下算出的是 1932053504 而不是 6227020800， 这是怎么回事？换成 long long 是"修好了"还是只是"多撑了几项"？ 为什么阶段七要专门讲类型宽度、任务七要区分 8/16/32 位数据？

关键提醒：累乘器 result 的初始值必须是 1（乘法单位元），写成 0 就永远是 0。 另外注意 if (n < 0) return -1; 这种"用返回值报告非法输入"的约定写法。

练习 7（挑战）行为封装 + 数组带出数据

  1. 把猜数游戏整体封装成 void guess_game(void)（内部含 srand、do-while、 次数统计），main 只写一句 guess_game();；
  2. 写 int num_to_digits(int n, int digits[])：把 n 的各位倒序拆进 digits （个位放 digits[0]），返回拆出了几位； ——等等，还没学指针！返回值只用来报"几位"，数据靠数组带出来。
  3. main：对 907 调用后，用返回的位数把 digits 正序打印出来（9 0 7）。 （这就是"数组带出数据"模式的又一次实战——和任务三的 result 同构。）
  4. 加分：处理 n = 0 的边界（0 是几位？），和负数的处理（注释里写清你的约定）。
