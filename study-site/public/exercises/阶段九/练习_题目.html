阶段九 练习题（动态内存与文件 IO）先做后看答案

纪律：先做后看答案；练习 3 是纸上作业，必须画图——内存图的功夫直接决定你以后调不调得出「随机崩溃」。 本阶段是弹性阶段：不赶进度，但每道题都要亲手编译、亲手 free，警告必须清零。 全程 -Wall -Wextra -std=c99；每写完一条 malloc/realloc，就在纸上记一笔「欠系统一次 free」。 文件题一律把测试文件生成在当前目录或 %TEMP%，跑完删掉——交付目录不许留下 .txt / .dat。

练习 1（基础）动态数组入门：求和、最值、逆序

从键盘读入 n（1 ≤ n ≤ 1000），用 malloc 申请 n 个 int 的数组，再读入 n 个整数，完成：

  1. 打印数组内容；
  2. 求和，并求最大值（同时打印它是第几个元素，从 1 开始数）；
  3. 逆序打印（原地交换或倒着遍历都可以）；
  4. free 并把指针置 NULL。

硬性要求：

  • malloc 后必须检查 NULL，失败时打印提示并 return 1；
  • 整个程序「一个 malloc 对应一个 free」，不许有第二条分配路径漏掉；
  • 字节数用 sizeof(int) * n 算，不许写死 4。

自测输入：第一行 5，第二行 3 9 1 7 5。应得到和 25、最大值 9（第 2 个）、逆序 5 7 1 9 3。

练习 2（基础）calloc 与零初始化：数字计数

给一个固定数组：

int data[] = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5, 8, 9, 7, 9, 3};

统计 0~9 每个数字出现的次数。

  1. 用 calloc(10, sizeof(int)) 开计数数组，遍历统计并打印 数字:次数；
  2. 再用 malloc + memset 写一遍，确认两份统计结果完全相同；
  3. 演示 memset 的 sizeof 陷阱（安全版）：

c int *p = malloc(10 * sizeof(int)); for (int i = 0; i < 10; i++) p[i] = 7; /* 先全部初始化，避免读未初始化值 */ memset(p, 0, sizeof p); /* 错！只清了指针大小 8 字节 = 2 个 int */

打印 p[0]、p[1]、p[2]，解释为什么是 0 0 7，并写出正确写法； 4. free 两块计数内存并置 NULL。

思考（注释里回答）：计数数组为什么必须先清零？如果拿 malloc 出来直接用会统计出什么？

练习 3（基础 · 纸上作业，必须做）内存图与泄漏推演

禁止上机运行（这段代码会崩溃或静默破坏内存），纯纸上推演。

#include <stdio.h>
#include <stdlib.h>

int *make_block(int n)
{
    int *p = malloc(n * sizeof(int));
    p[0] = 1;
    p[1] = 2;
    p[2] = 3;
    return p;
}

int main(void)
{
    int *a = make_block(3);
    int *b = a;
    printf("%d\n", b[0]);
    free(a);
    printf("%d\n", a[0]);
    b[1] = 99;
    free(b);
    a = NULL;
    int *c = malloc(4 * sizeof(int));
    c = malloc(8 * sizeof(int));
    free(c);
    return 0;
}

要求：

  1. 画堆栈内存图：标出 a、b、c 三个指针变量（栈）和它们指向的堆块，每块多大、归谁管；
  2. 逐行标注：哪一行之后 a 和 b 变成悬垂指针？哪一次 free 非法？为什么？
  3. 数一数：整个程序泄漏了几块内存、共多少字节？（按 64 位、int 4 字节、指针 8 字节算）
  4. 指出 make_block 里另一个「迟早出事」的隐患；
  5. 给出改正版：补 NULL 检查、去掉重复 free、补上漏掉的 free、free 后置 NULL。

提示：b = a 不是复制一块内存，只是把同一张门牌号抄了一份。

练习 4（提高）realloc 扩容：动态栈

实现一个 int 动态栈：

struct Stack {
    int *data;
    int length;
    int capacity;
};

接口：

  • int stack_init(struct Stack *s); 初始 capacity = 2；成功返回 1，失败返回 0；
  • int stack_push(struct Stack *s, int value); 满时容量翻倍；成功返回 1，realloc 失败返回 0；
  • int stack_pop(struct Stack *s, int *out); 空栈返回 0，否则弹出到 *out 返回 1；
  • int stack_top(const struct Stack *s, int *out); 只看不弹；空栈返回 0；
  • void stack_destroy(struct Stack *s); free 并把 data、length、capacity 全部清零。

要求：

  1. 每次扩容打印「旧容量 -> 新容量」和新 data 地址；
  2. push 1~10，每次打印 length 与 capacity；
  3. pop 三次并打印弹出的值，再 top 一次；
  4. 一直 pop 到空，验证空栈的 pop 和 top 都返回 0；
  5. destroy 后打印三个字段，确认已清零。

思考（注释里回答）：为什么扩容用「翻倍」而不是「每次 +1」？从容量 2 涨到 1024，两种策略各要 realloc 多少次？

练习 5（提高）文件统计：wc 的简化版

写一个统计文本文件的程序：行数、单词数、字符数。

  1. 程序自己生成测试文件 stage9_wc_demo.txt（至少 5 行，其中包含一个空行和一段连续空格），写完关闭；
  2. 以 "r" 重新打开，必须用 fgets 逐行读，不许一次性 fseek 读整块；
  3. 统计规则： - 行数 = fgets 成功次数； - 字符数 = 每行 strlen 累加（含行尾换行、含空格）； - 单词数 = 被空白（空格、制表符、换行）分隔的连续非空白串个数；
  4. 打印每行内容和三个统计值；
  5. 最后 remove 测试文件，并打印删除结果。

提示：单词计数用一个「当前是否在单词内」的状态变量 in_word；<ctype.h> 的 isspace 可以一次判断空格、制表、换行。

自测：若文件内容为 UPRE robot lab / C is simple but deep / 空行 / dynamic memory and file IO（中间三个空格）/ stage nine，每行都有换行符，则应为 5 行、15 个单词、77 个字符。

练习 6（提高）记录持久化：CSV 写读往返

定义：

struct Student {
    int    id;
    char   name[24];
    double score;
};
  1. 准备 5 条记录（学号、英文姓名、成绩），用 fprintf 写成 CSV 文件 stage9_ex6_scores.csv，一行一条、逗号分隔；
  2. fclose 后重新以 "r" 打开，用 fgets + sscanf("%d,%23[^,],%lf", ...) 读回；
  3. 逐字段和原数组比对（id 相等、姓名 strcmp 为 0、分数差的绝对值 < 1e-9）： 全部一致打印 ROUND TRIP OK，否则打印 FAIL 并指出第几条；
  4. 用读回的数据计算平均分并打印（两位小数）；
  5. remove 文件并打印清理结果。

要求：写入时检查 fprintf 返回值，读回时检查 sscanf 返回值；文件字段里不要出现英文双引号（带逗号的引号转义本题不涉及）。

思考（注释里回答）：如果姓名本身带逗号，这个 CSV 会怎样？该用什么办法解决？

练习 7（挑战）迷你通讯录：动态数组 + 文件 + 菜单

做一个命令行通讯录，记录「姓名」（不含空格，≤ 31 字符）和「电话」（≤ 19 字符）。

菜单：

1. 添加联系人
2. 删除联系人（按姓名）
3. 查找联系人（按姓名）
4. 列出全部
5. 保存到文件
6. 退出

硬性要求：

  1. 动态数组存记录：length 与 capacity 分离，满了 realloc 翻倍；失败要保住原数组；
  2. 启动时自动从 stage9_contacts.dat 加载（文件不存在就打印提示、从空通讯录开始）；
  3. 选 5 立即存盘；选 6 退出前再自动存盘一次（防止用户忘按 5）；
  4. 删除时把后面的记录前移，length 减一；找不到要提示；
  5. 所有文件操作检查返回值；fread 用「一次读一条、返回 1 才计数」的循环；
  6. 数据文件用二进制 fwrite / fread 存结构体数组，文件开头先写一个 int 记录条数。

验收脚本（PowerShell，管道喂输入）：

"1`nAlice`n13800001111`n1`nBob`n13900002222`n4`n6" | .\contacts.exe
.\contacts.exe   # 第二次启动，应能列出刚才的记录

第二次启动后按 6 退出，最后删掉 stage9_contacts.dat。

思考（注释里回答）：如果结构体加一个 int age; 字段，旧数据文件还能读吗？为什么？

验收提醒

  • 练习 1、2 是 malloc/free 的肌肉记忆，必须一次写对；
  • 练习 3 的图必须手画，画完拍照存进错题本——后面所有「随机崩溃」都靠这张图定位；
  • 练习 4 的 push/pop 是「动态数组 + 容量翻倍」的完整模板，练习 7 直接复用；
  • 练习 5 的 fgets 状态机是文件统计的通用骨架；
  • 练习 6、7 是「结构体 + 文件」的最小可用系统，入队后做上位机、日志解析都要用；
  • 全部完成后数一遍：malloc/calloc/realloc 成功几次，就必须 free 几次 （注意 realloc 成功会接管旧块，旧块不能再单独 free）。
