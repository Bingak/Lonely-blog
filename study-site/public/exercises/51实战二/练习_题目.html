51 实战二 练习题（定时器、串口、I2C/EEPROM）先做后看答案

纪律：先做后看答案；练习 3 是纸上作业，必须做——TMOD/TCON、定时器流水、I2C 时序图是进实验室的三块地基。 全部练习都在 PC 上完成：用 volatile unsigned char 模拟 SFR，用数组模拟 EEPROM / 串口对端，printf 打印时间、字节和总线电平；不需要 Keil、不需要烧录。 全程编译加 -Wall -Wextra -std=c99，警告必须清零，main 返回 int。 统一约定：晶振 12MHz（串口题用 11.0592MHz）、机器周期 = 12 / 晶振、串口 9600-8-N-1、AT24C02 写地址 0xA0 / 读地址 0xA1。

练习 1（基础）定时器初值计算

定时器 0 方式 1（16 位），12T。公式自己推一遍再写代码：

机器周期数 = 晶振频率(Hz) × 定时时间(s) / 12
重装值     = 65536 - 机器周期数（四舍五入到整数）
TH0 = 重装值 >> 8      TL0 = 重装值 & 0xFF
  1. 写 unsigned int reload_for(double mhz, double us, unsigned char *th, unsigned char *tl)，返回重装值；
  2. 打印 12MHz 下 1ms、500us、20ms、50ms 的机器周期数、重装值、TH0、TL0、实际定时与误差；
  3. 换成 11.0592MHz 再打一遍，指出哪几个值不是整数个机器周期、误差多大；
  4. 反算校验：对每一行把 TH0 << 8 | TL0 拼回去，确认 65536 - 重装值 等于实际写入的计数；
  5. 回答（写进注释）： - 12MHz 下方式 1 一次最长能定时多久？为什么？ - 想要 1 秒的节拍该怎么办？ - 为什么方式 1 每次中断都要重装，而方式 2 不用？ - 中断响应本身要 3~8 个机器周期，1ms 节拍跑 1000 次会累积多少误差？可以怎么补？

练习 2（基础）毫秒计时器（启动 / 停止 / 清零）

做一个 0.000 ~ 59.999 秒的毫秒计时器，用 1ms 定时器节拍推进。

要求：

  1. 状态机只有两个状态：停止 / 运行；三个按键动作：启动、停止、清零；
  2. 数据结构自选（结构体更好），但时间只由 tick 累加产生，不许用 clock()、time() 或 Sleep()；
  3. 每来一个毫秒节拍调用 timer_tick()；只有 运行 状态才让时间 +1；
  4. 模拟这样一串按键事件（用 tick 号表示发生的时刻）： - tick 0 启动；tick 1234 停止；tick 1500 再启动；tick 2000 清零；tick 2500 停止；
  5. 每次状态变化打印一行，形如 >>> tick 1234：运行 → 停止，显示 1.234s；
  6. 最后打印：总 tick 数、显示值、两者是否一致；再打印 3 次「清零后重新计时」的结果；
  7. 注释里回答：为什么清零不能只把显示变量置 0？停止 状态下按清零和按启动分别会发生什么？

练习 3（基础 · 纸上作业，必须做）寄存器推演 + 定时器流水 + I2C 时序图

A 部分 TMOD / TCON 位含义

  1. 填出 TMOD 的 8 位：GATE1 C/T1 M1_1 M0_1 | GATE0 C/T0 M1_0 M0_0，说明每一位的作用；
  2. 填出 TCON 的 8 位：TF1 TR1 TF0 TR0 | IE1 IT1 IE0 IT0，说明哪些是硬件置位、哪些要软件清；
  3. 写出下面几个 TMOD 值的含义： - 0x01、0x10、0x21、0x02、0x20；
  4. 定时器 0 方式 1 启动的完整步骤（按顺序写：TMOD → TH0/TL0 → ET0/EA → TR0），每一步为什么不能省？

B 部分 定时器流水推演

12MHz，定时器 0 方式 1，初值 TH0 = 0xFC、TL0 = 0x18。

  1. 这个初值对应的重装值、机器周期数、定时时间各是多少？
  2. 要定时 250ms，需要溢出多少次？列一张表，写前 5 次溢出的「重装值 → TF0 → 节拍数」；
  3. 如果中断服务函数里忘了重装 TH0/TL0，下一次溢出要多久？此时 1 秒能进几次中断？
  4. 主循环用 while (!flag); 等 250ms，和「中断里 tick++，主循环看到 tick 变化就干活」相比，各有什么问题？
  5. 如果 1ms 节拍要连续跑 1 小时，按每次中断多花 5 个机器周期算，累计慢多少毫秒？该用什么办法补？

C 部分 I2C 时序图推演

AT24C02，7 位地址 0x50（写字节 0xA0、读字节 0xA1），要把 0x5A 写到内部地址 0x23，再读回来。

  1. 画出「字节写」的 SCL/SDA 波形，至少标出：START、0xA0 的 8 位、ACK、0x23 的 8 位、ACK、0x5A 的 8 位、ACK、STOP；每一位写出 bit7~bit0；
  2. 画出「随机读」的波形，说明为什么要有重复起始 Sr，以及读完后主机为什么回 NACK；
  3. 回答： - 数据在 SCL 的上升沿还是下降沿被采样？SDA 允许在 SCL 高电平期间变化吗？为什么？ - 为什么 SCL/SDA 必须开漏 + 上拉，不能推挽输出？ - 第 9 个时钟从机不拉低 SDA 代表什么？主机该怎么处理？ - 字节写后为什么要等 5ms？不等就发下一条命令会发生什么？ - 写 0x23 和写 0x27 在「页」上有什么区别？（AT24C02 一页 8 字节）

练习 4（提高）串口命令解析（led on / led off / beep）

命令表：led on、led off、beep。空格可以多个，Tab / 回车 / 换行也算分隔符；大小写敏感。

要求：

  1. 用「状态 + 缓冲」的状态机解析，命令可以跨字节到达（例如先来 le，再来 d on）；
  2. 一条流里可以有多条命令（led on led off beep），按顺序打印识别结果与执行动作；
  3. 三种错误都要给明确提示，且报错后能继续解析后面的命令： - led onx：命令后面粘了多余字符； - on：缺 led 前缀； - led（流结束）：命令不完整；
  4. 打印每条输入流的「命令序列」和「错误条数」，最后汇总；
  5. 注释里回答：为什么不能每收到一个字节就 strcmp 一次？缓冲开多大合适？

练习 5（提高）中断接收与 LED 控制

串口中断接收，ISR 把字节塞进 8 字节环形缓冲；主循环每 2ms 才来取一次（模拟它在忙别的事）。

命令（单字节）：A = 8 个 LED 全亮、B = 全灭、T = 翻转 LED0、? = 打印当前 P1。

要求：

  1. 模拟 6 个字节在 6ms 内陆续到达（每 1.042ms 一帧），主循环 2ms 才消费一次，证明一个字节都不丢；
  2. 打印每次进 ISR 后的 head/tail/count，以及主循环消费后的 P1 二进制（0 = 亮，低电平点亮）；
  3. 再把 10 个字节塞进 8 字节缓冲，制造一次溢出：打印丢了几个字节、丢的是哪几个；
  4. 对比实验：把接收改成查询方式，主循环「忙 2ms」期间会漏掉几个字节？
  5. 注释里回答：ISR 里为什么不能 printf、不能 delay？环形缓冲的 head/tail 谁写谁读？

练习 6（提高）I2C 读写 EEPROM（页写 + 顺序读）

AT24C02 一页 8 字节。把数组 {0x11,0x22,0x33,0x44,0x55,0x66,0x77,0x88} 写到内部地址 0x40，再顺序读回。

要求：

  1. 实现 i2c_start/stop/write_byte/read_byte/ack，SCL/SDA 每次变化都要打印（可只详细打印第一笔）；
  2. 页写：一次 START + 地址 + 8 个数据 + STOP；每写一页等 5ms；
  3. 顺序读：假写地址 → 重复起始 → 读方向 → 连续读 8 个字节，前 7 个回 ACK、最后一个回 NACK；
  4. 打印每个字节的地址、写入值、读回值、校验结果；最后算一个累加和；
  5. 加分：故意从 0x44 开始写 8 个字节，观察 AT24C02 的页内回绕（地址低 3 位循环），解释为什么跨页要拆成两次写；
  6. 注释里回答：页写和字节写各适合什么场景？写周期没等完就发下一条命令，从机会怎么响应？

练习 7（挑战）断电恢复计数器

用 AT24C02 保存一个 16 位开机次数计数器：地址 0x00 存低字节、0x01 存高字节、0x02 存校验和（低 ^ 高 ^ 0xA5）。

要求：

  1. 上电流程：读 3 个字节 → 0xFF 0xFF 视为新器件，计数从 0 开始 → 校验错则告警并归 0 → 计数 +1 → 写回（先写数据，最后写校验和）；
  2. 模拟 3 次「上电 → 计数 → 断电」，打印每次读到的原始字节和最终计数；
  3. 模拟一次「校验和被人为改坏」，验证程序能发现并重置，而不是显示一个乱数；
  4. 打印每次写 EEPROM 的事务时序（可复用练习 6 的 I2C 代码）；
  5. 注释里回答： - 为什么校验和要最后写？ - 如果写到一半断电，可能出现哪几种字节组合？程序怎么自保？ - AT24C02 擦写寿命约 100 万次，这种「每次开机写一次」的用法能用多久？有没有更省寿命的做法？

验收提醒

  • 练习 3 是纸上作业，必须做：TMOD/TCON 各位、定时器流水、I2C 波形，三样都要能默画；
  • 练习 1、2 是「手熟」题：初值公式、1ms 节拍、启停清零要练到不看笔记能写；
  • 练习 4、5 是「字节流 → 命令 → 动作」的完整链路，实验室里的串口题都长这样；
  • 练习 6、7 是 EEPROM 的两条主线：会读写，还要会在断电面前保护数据；
  • 全部完成后对照教程的验收清单，把错题记进错题本。
