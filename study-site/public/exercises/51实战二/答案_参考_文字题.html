51 实战二 参考答案（练习 3 · 纸上作业）参考答案

先自己做，再对答案。三部分都要过：TMOD/TCON 位、定时器流水、I2C 时序图。 约定：12MHz → 1 个机器周期 = 1us；定时器 0 方式 1；AT24C02 写地址 0xA0、读地址 0xA1。

A 部分 TMOD / TCON 位含义

TMOD（地址 0x89，不能位寻址，只能整字节写）

位 7 6 5 4 3 2 1 0
名称 GATE1 C/T1 M1_1 M0_1 GATE0 C/T0 M1_0 M0_0
作用 定时器 1 门控 定时器 1 定时/计数 方式高位 方式低位 定时器 0 门控 定时器 0 定时/计数 方式高位 方式低位
  • GATE = 0：只由 TRx 软件位启动/停止（最常用）；
  • GATE = 1：还要 INTx 引脚为高电平才放行，用于测外部脉冲宽度；
  • C/T = 0：定时器，数内部机器周期；C/T = 1：计数器，数 T0/T1 引脚上的下降沿；
  • M1 M0：
M1 M0 方式 说明
0 0 方式 0 13 位定时器（TLx 低 5 位 + THx 8 位），老 8048 兼容
0 1 方式 1 16 位定时器，范围 1~65536 个机器周期，最常用
1 0 方式 2 8 位自动重装：TLx 溢出后硬件把 THx 装回 TLx
1 1 方式 3 定时器 0 拆成两个 8 位；定时器 1 停止（一般不用）

TCON（地址 0x88，可位寻址）

位 7 6 5 4 3 2 1 0
名称 TF1 TR1 TF0 TR0 IE1 IT1 IE0 IT0
作用 T1 溢出标志 T1 运行控制 T0 溢出标志 T0 运行控制 外部中断 1 标志 外部中断 1 触发方式 外部中断 0 标志 外部中断 0 触发方式
  • TF0/TF1：硬件在溢出时置 1；进中断后必须软件清 0（TF0 = 0;），否则会反复进中断；
  • TR0/TR1：软件置 1 启动、清 0 停止；
  • IE0/IE1：外部中断标志，硬件置位、进 ISR 后清；
  • IT0/IT1：0 = 低电平触发，1 = 下降沿触发。

几个 TMOD 值的含义

TMOD 含义
0x01 定时器 0，方式 1（16 位定时），GATE0 = 0，软件 TR0 启动
0x10 定时器 1，方式 1（16 位定时）
0x21 定时器 1 方式 2（0x20）+ 定时器 0 方式 1（0x01）：T0 做 1ms 节拍，T1 做波特率
0x02 定时器 0，方式 2（8 位自动重装）
0x20 定时器 1，方式 2（8 位自动重装，常做波特率发生器）

定时器 0 方式 1 启动步骤

TMOD = 0x01;        /* ① 选方式：16 位定时，不门控 */
TH0  = 0xFC;        /* ② 装初值高字节 */
TL0  = 0x18;        /*    装初值低字节 */
ET0  = 1;           /* ③ 允许定时器 0 中断 */
EA   = 1;           /*    开总中断 */
TR0  = 1;           /* ④ 启动计数 */

每一步都不能省：

  • 不写 TMOD：复位值是 0x00，方式 0 只有 13 位，初值全错；
  • 不装 TH0/TL0：从 0 开始数，第一次要等 65536 个周期；
  • 不开 ET0/EA：溢出只置 TF0，不进中断，tick 永远不涨；
  • 不置 TR0：计数器根本不走。

B 部分 定时器流水推演

初值 TH0 = 0xFC、TL0 = 0x18：

  • 重装值 = 0xFC18 = 64536；
  • 机器周期数 = 65536 − 64536 = 1000；
  • 12MHz 下 1 个机器周期 1us → 定时 1000us = 1ms。

250ms 要溢出多少次

250ms ÷ 1ms = 250 次。前 5 次溢出：

溢出次数 重装值 重装后 TH0/TL0 TF0 节拍 tick
1 64536 0xFC / 0x18 硬件置 1 → 中断里清 0 1
2 64536 0xFC / 0x18 同上 2
3 64536 0xFC / 0x18 同上 3
4 64536 0xFC / 0x18 同上 4
5 64536 0xFC / 0x18 同上 5

到第 250 次溢出时 tick = 250，正好 250ms。

忘了重装会怎样

方式 1 溢出后计数器归 0，不重装就从 0 数到 65536：

  • 下一次溢出要 65536 个机器周期 = 65.536ms；
  • 1 秒只能进约 1000 / 65.536 ≈ 15 次中断，而不是 1000 次；
  • 现象：灯闪得极慢、秒表走得极慢，而且第一次 1ms 之后就“变慢”了。

查询等标志 vs 中断 tick

while (!flag);          /* 查询：CPU 死等，按键、串口全错过 */
  • 查询方式：这 250ms 里主循环什么都干不了；flag 还必须 volatile，否则可能被优化成死循环；
  • 中断方式：ISR 只 tick++，主循环看到 tick 变化再干活，串口/按键都能及时响应；
  • 注意：主循环读 tick 也要 volatile，并且 16 位变量在 8 位机上的读写不是原子的，必要时先关中断再读。

1 小时累计误差

  • 3,600,000 次中断 × 5 个机器周期 = 18,000,000 个机器周期；
  • 12MHz 下 = 18,000,000us = 18,000ms = 18 秒；
  • 补偿：中断多花了 5 个周期，等于每次定时变长，应把计数改短 5 个周期（重装值 +5）；
  • 更稳的办法：方式 2 自动重装减少软件开销，或用外部 RTC。

C 部分 I2C 时序图推演

字节写：0x5A 写到 0x23

事务：START → 0xA0 + ACK → 0x23 + ACK → 0x5A + ACK → STOP

0xA0 = 1010 0000，0x23 = 0010 0011，0x5A = 0101 1010，全部高位先发。

        START   A6 A5 A4 A3 A2 A1 A0 RW  ACK   7  6  5  4  3  2  1  0  ACK ...
SCL  ‾‾‾\___/‾‾‾\_/‾‾‾\_/‾‾‾\_/‾‾‾\_/‾‾‾\_/‾‾‾\_/‾‾‾\_/‾‾‾\_/‾‾‾\___ ...
SDA  ‾‾‾‾\___/‾‾‾‾‾‾‾\___/‾‾‾\_____/‾‾‾\_________/‾‾‾\___/‾‾‾\_______ ...
       SDA 高→低    1    0    1   0  0  0  0  0   0(ACK)

逐位表（省略 SCL 的 9 个脉冲，只列 SDA 在第 1~8 个高电平期间的电平）：

字节 b7 b6 b5 b4 b3 b2 b1 b0 第 9 位
0xA0 1 0 1 0 0 0 0 0 从机拉低 = ACK
0x23 0 0 1 0 0 0 1 1 从机拉低 = ACK
0x5A 0 1 0 1 1 0 1 0 从机拉低 = ACK

STOP：SCL 高时 SDA 由 0 变 1。

随机读：0x23 读回 0x5A

事务：

START → 0xA0 + ACK → 0x23 + ACK → Sr → 0xA1 + ACK → 读 0x5A（8 位）→ 主机 NACK → STOP

读出的 0x5A = 0101 1010，从机在 SCL 低时改 SDA，主机在 SCL 高时采样。

为什么要重复起始 Sr：

  • 先“假写”一次，把内部地址指针设到 0x23；
  • 不能发 STOP，否则器件释放总线、地址指针状态可能丢；
  • Sr 重新开始一个事务，但不释放总线，紧接着发读地址 0xA1。

为什么读完回 NACK：

  • ACK 的意思是“还要下一个字节”；
  • 主机只要 1 个字节，第 9 个时钟放开 SDA（NACK），从机就知道该释放 SDA；
  • 主机随后才能发 STOP（STOP 要求 SCL 高时 SDA 由低变高，若从机还拉着 SDA 就发不出来）。

问答

  1. 采样沿：数据在 SCL 上升沿被采样（更准确说高电平期间有效）；SDA 只允许在 SCL 低电平期间变化。SCL 高时改 SDA 会被当成 START（下降）或 STOP（上升）。
  2. 开漏 + 上拉：总线上有多个主机/从机，推挽输出会出现“一个输出高、一个输出低”直接短路；开漏只能拉低、释放由上拉拉高，天然实现“线与”，谁拉低都有效。
  3. 第 9 个时钟不拉低：NACK。含义：地址不匹配 / 器件忙（写周期未完成）/ 主机读完了。主机应停止或重试。
  4. 5ms 写周期：AT24C02 收到 STOP 后把数据写进浮栅，期间不响应任何命令。不等就发下一条，器件回 NACK；正确做法是延时 5ms 或“ACK 轮询”（反复发起始 + 设备地址，直到 ACK）。
  5. 页边界：AT24C02 一页 8 字节，页内地址低 3 位循环。从 0x23 连续写 8 个字节，地址依次是 0x23, 0x24, 0x25, 0x26, 0x27, 0x20, 0x21, 0x22（后 3 个回绕到页首），不会进入 0x28。 所以跨页写必须拆成两次事务；写 0x27 再连续写 8 个字节也会回绕到 0x20。

常见错误（自查）

  • ❌ 把 TMOD 的 GATE 位当成“启动位”——启动是 TCON 的 TR0；
  • ❌ 忘了清 TF0——中断会反复进，tick 飞涨；
  • ❌ 方式 1 忘了重装——周期从 1ms 变成 65.536ms；
  • ❌ 把 I2C 的 ACK 当成“从机发 0”——ACK 是从机把 SDA 拉低，第 9 个时钟为 0；
  • ❌ 读最后一个字节回 ACK——从机继续输出，主机发不出 STOP；
  • ❌ 写 EEPROM 不等 5ms——下一条命令 NACK，数据可能没写进去。
