# 关于我 / About Me

你好喵~ 我是 **LonelyBing**，一个普普通通的大学生，数字世界里默默无闻的一片叶子。

先说结论：本站基座是开源主题 [Firefly](https://github.com/CuteLeaf/Firefly)（V6.16.8），上面那些皮肤、内脏、小心思全是本尊一行一行魔改出来的（恼）。这一页就是魔改清单，折腾过程大多写成了博客文章——不想看原理的可以直接跳到文末😅（乐）

## 🛠️ 关于本站

框架是 **Astro**，主题 Firefly 的上游还有 [Fuwari](https://github.com/saicaca/fuwari)，感谢 [CuteLeaf](https://github.com/CuteLeaf) 与 [saicaca](https://github.com/saicaca) 的开源贡献。主要改动如下喵~

### ✨ 导航栏与交互

- **胶囊导航栏**：菜单收进一颗胶囊，悬停时有滑动指示器跟着鼠标溜达——不是每个按钮各自闪一下，是整块一起滑，看着就高级（恼）.
- **滚动形变动画**：往下滚，全宽胶囊会平滑收拢成屏幕居中的一颗悬浮小胶囊，滚回顶部又舒展回去，像只缩成球的刺猬（乐）. 人话版原理：CSS 过渡不了 `fit-content`，所以本尊先按 `max-content` 量出内容的自然宽，再写回像素值做插值. 没用双元素 DOM 交接那套花活，单元素就够了（对，本尊就是这么懒，悲）.
- **鼠标聚光灯**：导航栏上有一层跟着鼠标跑的高光，像手电筒扫过去一样.
- **圆角过渡动画**：站名和按钮平时是圆角，悬停平滑过渡成胶囊形，点下去还有按压反馈.
- **站名悬停资料卡**：鼠标放到左上角站名上会弹出一张小卡片——头像、昵称、签名、社交链接，加上**当年的发文贡献热力图**（GitHub 同款小绿格），以及**建站以来的实时运行时间**（年/月/日/时/分/秒，每秒刷新）. 点头像区还能跳回本页喵~
- **搜索框**：全胶囊造型，聚焦会变宽；小胶囊态下列间距自动加宽，不会跟菜单挤在一起（这个间距是本尊亲手调的，恼）.

### 🎨 主题色与视觉

- **全局主题色系统**：基于 `oklch()` 色空间，一个 `--hue` 变量管全站配色——改一个数字整个站换一身衣服（本站当前为青蓝色 hue 200）.
- **文章卡片蓝色细边框**：首页文章卡片带一圈 1.5px 青蓝色边框，暗色模式自动调亮度，卡片在壁纸上不会糊成一团.
- **显示设置面板**：点导航栏的调色盘按钮弹出浮层，**不刷新、不重新构建**就能切壁纸四模式（纯色 / 横幅 / 全屏 / 覆盖透明）、全屏布局、文章列表排布、主题色相、卡片样式与樱花特效. 偏好全存 localStorage，刷新不丢喵~
- **Material 3 动态配色**：面板里能切 9 种配色风格和 2 种配色规范（MD3 2021 / M3E 2025），背后是 HCT 色空间引擎实时重算. 默认那一档**不注入任何覆盖变量**，所以本站看着还是原生 oklch 的味道——你主动切了才换 M3 配色（配色引擎借鉴自 [Shirone](https://github.com/LyraVoid/Shirone)，感谢 [LyraVoid](https://github.com/LyraVoid) 的开源分享喵~）.
- **背景纹理**：纯色模式可叠一层装饰纹理，六种可选（无纹理 / 星芒光斑 / 极客点阵 / 流光等高线 / 几何晶体 / 落樱微瓣），取色全由 `--hue` 推导，换主题色纹理自己跟着变. 星芒会呼吸、等高线会流光、樱花会斜着飘，`prefers-reduced-motion` 下自动静止（够体贴吧，乐）. 切到壁纸模式会自动让位，不打架.

### 🎵 音乐播放器

- **波浪进度条**：播放时是一条涌动的正弦波，暂停时缓缓落成直线——升起快、落下慢. 支持点击和按住拖动实时预览进度，颜色跟着主题色走. 波形用的是 M3 Expressive LinearWavy 算法，借鉴自 Shirone 的 `wavy-progress` 实现喵~
- 歌单、歌词、播放模式逻辑仍是原来的 Meting 方案，这次只重画了 UI 层（不敢动逻辑，怕一动手就炸，悲）.

### 📊 访问统计

- **不蒜子（Busuanzi）计数**：页脚展示全站 PV / UV，文章页展示单篇阅读量，零后端、零配置.
- **建站存活计时**：页脚「本站已存活 X 天 X 小时 X 分 X 秒」，从 2026.9.12 开始每秒刷新.

### 🧩 页面功能

- **项目页评论区**：项目展示页接入评论系统，frontmatter 的 `comment` 字段可按项目单独开关.
- **全屏随机壁纸 + 名言**：每次刷新随机换图，底部附一句随机中文名言（偶尔抽到奇怪的，随缘吧恼）.
- **在线写作**：配了 `.pages.yml`（Pages CMS），GitHub 网页端直接写文章、发动态，不用本地跑构建.
- **更新日志页**：拉取 GitHub 仓库 commit 记录，按类型（新功能/修复/优化等）宽松分类与分页，不重新构建就能看到最新改动. 配了 Token 限额从 60 次/小时提到 5000 次/小时.
- **友链自动申请**：友链页填四项表单（站点名称 / 链接 / 头像 / 描述），过 **Cloudflare Turnstile** 人机验证后，Worker 自动在仓库新建分支、追加条目、开一个 PR，本尊点合并即上线，全程不用手改一行代码喵~ 重复提交会被 409 挡掉，内网和非 http(s) 链接一律拒收.

### ✍️ 内容工坊（后台）

- **墨驿 InkPost**：藏在站内的零依赖、离线可用静态后台. 文章配置全部表单化——引号、冒号自动转义，一行 YAML 都不用手写；编辑自动保存、刷新不丢；内置多文档库、浅色/深色/跟随系统三态主题、本地 Markdown 导入和写作快捷键（Ctrl+B 加粗之类）. 写完一键提交 GitHub，Cloudflare 自动构建上线. 支持文章/项目/动态/相册四类内容，还能从仓库拉已有内容在线编辑、相册批量加图、视频嵌入自动识别 B 站/YouTube、移动端也能正常用喵~
- **登录页**：本尊给它换过一身行头——背景接了和全站同源的随机图 API，逐个预加载、全挂就安静回落纯色（摔了也不吭声，悲）；登录卡是半透明磨砂玻璃，输入框也做成半透明，不会在玻璃上顶出实心块.
- **登录安全**：用户名和密码存在 Cloudflare Worker 的 Secrets 里，前端拿不到明文；登录要过 Turnstile 人机验证，接口带同 IP 限流，签发 12 小时会话，锁定即失效. 入口藏在导航栏「链接」下拉菜单里，想找茬请先学会逛菜单（乐）.

### ⚙️ 个性化配置

- 相册、打赏页、看板娘、评论区等均替换为自己的内容与账号，站点信息（标题、头像、社交链接等）全部按本站实际配置.
