先把结论摆出来：C 里 `3 / 4` 的结果是 0，不是 0.75。我一开始不信，还在注释里写过一句"不等于 -0.75，而是 3"喵~

```c
#include <stdio.h>

int main() {
    printf("算式在C语言里的结果是%d\n", 1 + 2 - 3 / 4 * 5);
    printf("算式在C语言里的结果是%d\n", 10 % 3);
    printf("算式在C语言里的结果是%d\n", 10 % -3);
    return 0;
}
```

两个整数相除，小数部分直接被丢掉。`3 / 4` 先变成 0，后面再乘 5 也还是 0。算式看着没毛病，跑出来的结果却跟脑子里想的对不上。那时候我才反应过来，做这类运算得先看操作数的类型。

## `printf` 里一个 `%` 也能整出这么多事

变量这块一开始就是赋值、打印，挺无聊。后来我把格式符挨个试了一遍：整数、小数、字符、字符串、地址，还有补零、左对齐、十六进制。代码没几行，输出倒是一大串。

```c
int a = 100;
double b = 3.14159;
char c = 'A';
char s[] = "hello";

printf("%d\n", a);
printf("%05d\n", a);
printf("%x\n", a);
printf("%.2f\n", b);
printf("%c\n", c);
printf("%s\n", s);
printf("%p\n", (void *)&a);
```

同样一个 `char`，用 `%d` 打出来是数字，用 `%c` 打出来是字母。不是它变了，是我给它选了不同的显示方式。`printf` 看着老实，可格式串写错了它不会替你猜，你写什么它就照着打什么，认认真真吐一堆垃圾出来 XD

## `if` 写着写着，电梯楼层全乱了

开始写 `if` 之后，练习题从"打印一个数"变成"让程序选一条路"：判断流量够不够、商品价格在哪一档、会员打几折。后来又摸到 `switch`，我拿电梯楼层做了个小例子，写完回头一看，这段现在很想删掉重写。

```c
case 3:
    printf("电梯到达3楼\n");
    break;
case 4:
    printf("电梯到达3楼\n");
    break;
case 5:
    printf("电梯到达3楼\n");
    break;
```

4 楼和 5 楼也显示到达 3 楼，复制粘贴完忘了改数字，就这么漏了。这种错不高深，但确实容易看漏。`break` 也不能忘，忘了它选完一个 case 还会继续往下走。我当时想的是"选中了就结束"，可 C 的意思很直接：你没写，我怎么知道。

逻辑运算符也一起练了。`&&` 是两边都得满足，`||` 是满足一个就行。闰年那题把括号和优先级往里一摆，看着像一串密码，拆开看还行，全挤在一行就开始怀疑自己。

## 终于能自己往里输了

之前的值全写死在代码里，改个数还得回去动源码。学了 `scanf` 之后，键盘上敲的东西就能交给程序了。

```c
#include <stdio.h>

int main() {
    int a;
    scanf("%d", &a);
    printf("a=%d\n", a);
}
```

`&a` 这个不能少，`scanf` 得知道读到的值往哪儿放。后来又把商品类别和价格一起读进来，扔给 `switch` 和 `if` 算折扣。格式串里的逗号得跟输入对上，空格和逗号这种小东西，错开一位它就不按我想的来。

## 现在是循环

`for` 先拿来把 1 打到 10。

```c
for (int i = 1; i <= 10; i += 1) {
    printf("%d\n", i);
}
```

然后 `while` 和 `do while` 也写了，一边累加 1 到 100 里的偶数，一边重复打印数字。两者的差别在检查条件的时机：`while` 先看要不要做，`do while` 先做一次再看。光听这一句像绕口令，两种都敲一遍反倒好记~

```c
int i = 0;
while (i <= 10)
{
    printf("%d\n", i);
    i += 1;
}

int z = 1;
do
{
    printf("%d\n", z);
    z += 1;
} while (z <= 10);
```

循环变量记得改。少写一行递增，程序就会一直循环下去，停不了。写到这儿我大概懂了大家为什么总说括号和分号重要——平时看不出区别，少写一个就报错，或者跑出不对的结果。

C 还没学完，循环也只是刚摸到。现在的做法就是把课上碰到的东西写成小程序，看输出跑没跑偏，错了就回去找，找不到就再多看几遍。报错有时候比我还爱说废话 :(
