## 🌟 项目概述

**MiBand-Daily-Word-Practice** 是一个跑在小米手环 9 Pro 上的每日背单词小程序。它把「墨墨背单词」最核心的思路——**让记忆越模糊的单词出现得越频繁**——搬到了一块腕上屏幕里，让你在不能带手机的场合也能刷单词。

**⭐ 开源地址：[https://github.com/Bingak/MiBand-Daily-Word-Practice](https://github.com/Bingak/MiBand-Daily-Word-Practice)**

**📖 开发文档 / 使用说明：[Vela 快应用开发指南](https://iot.mi.com/vela/quickapp/zh/guide/)**

**❤️ 爱发电：[https://ifdian.net/a/LonelyBing](https://ifdian.net/a/LonelyBing)**

::github{repo="Bingak/MiBand-Daily-Word-Practice"}

项目的诞生理由相当朴素：高中三年，这块 9 Pro 打了 1 年半的台球和斗地主，是时候让它干点正事了。作者此前完全没有前端基础，为了把小程序写出来现学了 HTML / CSS / JS；设计灵感则直接来自高中一直在用、却因为不能带手机而无法在校园里真正用起来的墨墨背单词。

> [!NOTE]
> 内置词表包含大量单词汉译与短语，词库文件体积约 **6MB**。手环存储空间紧张的话，建议先清理出足够空间再安装。

## 🚀 技术架构

- **运行平台**：小米手环 9 Pro，基于小米 **Vela 快应用（Quick App）** 框架
- **技术栈**：JavaScript 编写业务逻辑，界面使用类 HTML / CSS 的组件描述，整体零后端依赖
- **开发工具**：使用 **AIoT IDE** 编译、调试与装机
- **数据存储**：词库与学习进度全部保存在设备本地，背诵过程无需联网

## 🎯 核心功能

### 四档记忆状态

每个单词在被复习时，你可以给出四种反馈。这一档选择直接决定它今后的出场频率：

| 状态 | 颜色 | 含义 | 后续行为 |
| --- | --- | --- | --- |
| 熟知 | 🟢 绿色 | 这个词已经是我兄弟了 | **今后练习中不再出现** |
| 认识 | ⚪ 白色 | 见过面，不算熟 | 计入待练习，当天重复 **3 次** |
| 模糊 | 🟡 黄色 | 似曾相识，但不确定 | 计入待练习，当天重复 **5 次** |
| 忘记 | 🔴 红色 | 对不起，我们第一次见 | 计入待练习，当天重复 **7 次** |

### 每日抽词与间隔重复

- 除「熟知」外的所有单词，统一归入 **「待练习单词」** 池子
- 每天从池子里 **随机抽取 50 个**单词作为当天的任务
- 当天反复出现的次数按记忆状态区分（认识 3 次 / 模糊 5 次 / 忘记 7 次），越生疏的单词被"折磨"的次数越多
- 一旦标记为熟知，该词便彻底退出练习队列，不再浪费时间

### 复习与学习统计

除了当天的任务，还提供 **复习功能**，可以回看 **近 7 日学习统计**。数据不撒谎——坚持与否，一眼就能看出来。

### 简洁的界面

UI 走极简路线，没有花哨动效。理由也很诚实：作者懒得加（乐）。

## 🧩 词库与数据格式

小程序内置 **高中 6200 词汇表**（默认词库）。词库文件 `words.js` 中每一项都是三段式结构：

```js
{
  "english": "terrible",
  "phonetic": "[ˈterəbl]",
  "chinese": "a. 可怕的 | 糟糕的，差劲的 | feel terrible 感觉很难受 | terrible mistake 严重的错误"
}
```

| 字段 | 说明 |
| --- | --- |
| `english` | 英文单词 |
| `phonetic` | 音标 |
| `chinese` | 释义，多个义项与短语之间用 `\|` 分隔 |

> [!TIP]
> 想换成自己的词表（四六级、考研、雅思等）时，只要保持上述三段式结构替换 `words.js` 即可。有定制需求也可以联系作者。

## 📖 使用说明

### 环境准备

1. 准备一台小米手环 9 Pro，并确保存储空间充足
2. 在电脑上安装 **AIoT IDE**
3. 参考官方文档熟悉 Vela 快应用的工程结构与调试流程：[https://iot.mi.com/vela/quickapp/zh/guide/](https://iot.mi.com/vela/quickapp/zh/guide/)

### 编译与安装

```bash
# 1. 克隆仓库
git clone https://github.com/Bingak/MiBand-Daily-Word-Practice.git

# 2. 用 AIoT IDE 打开工程目录
# 3. 连接手环，执行编译并在设备上安装运行
```

### 日常使用

1. 打开小程序，进入当天的练习，系统自动从「待练习单词」中抽取 50 个
2. 逐个作答，按记忆实况选择 **熟知 / 认识 / 模糊 / 忘记**
3. 生词会被重复叩问多轮，直到当天任务完成
4. 有空时翻一翻 **近 7 日学习统计**，看看自己有没有偷懒
