以前写文章要开编辑器、手写 YAML 头部、再手动提交仓库，流程又长又容易写错格式。这次干脆给博客加了个在线后台——**墨驿 InkPost**，打开网页就能写，写完一键推送，Cloudflare 自动构建上线喵~

![墨驿后台主界面](https://img.lonelybing.top/file/post/post.png)

整个后台是纯静态的，零依赖、离线可用，就放在博客仓库里，没有引入任何框架喵~

---

## 一、表单化配置，告别手写 YAML

以前每篇文章开头都要手写一段 FrontMatter，冒号、引号稍微写错一个博客就解析报错。现在全部做成了表单：标题、日期、描述、标签、分类、封面、协议……填完自动生成规范的 YAML，引号和冒号自动转义，不会再因为格式问题翻车了喵~

- **封面三种模式**：不使用 / 随机图 API / 自定义地址
- **开源协议预设**：MIT、GPL、CC 系列等 14 种，选中自动填好名称和链接
- **时间精度切换**：只写日期，或者精确到时分秒
- **自定义字段**：主题扩展字段可以自由增删，原样写进 FrontMatter

右侧还有四栏实时预览：渲染效果、大纲、YAML 源码、完整源码，写的时候随时能看最终长什么样~

## 二、编辑器体验

编辑器该有的都有，而且全是快捷键驱动：

| 功能 | 说明 |
| --- | --- |
| 快捷键 | `Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+F` 查找替换等 |
| `/` 斜杠命令 | 行首输入 `/` 唤出 20 项命令菜单，标题、列表、表格、代码块一键插入 |
| 扩展语法 | 视频嵌入（自动识别 B 站 / YouTube 链接生成 iframe）、GitHub 卡片、提示块、图片画廊、代码组、内部链接 |
| 智能输入 | 列表自动续写、有序列表自动编号、选中文本按 `*` `(` 自动包裹 |
| 富文本粘贴 | 从网页复制的内容粘贴进来自动转成 Markdown |
| 行级操作 | `Alt+↑/↓` 移动整行、`Ctrl+D` 复制行 |

自动保存也做了：编辑内容实时存到浏览器本地，刷新页面、关掉再开都不会丢喵~

## 三、四种内容类型

后台支持博客的全部四种内容，每种都有对应的专属表单：

![文章与项目](https://img.lonelybing.top/file/post/项目.png)

- **📄 文章 Post**：标准博客文章，全套 FrontMatter 字段
- **🧩 项目 Project**：带项目链接、状态、排序的项目展示
- **💬 动态 Dynamic**：轻量碎碎念，只需要时间、地点几个字段

![动态编辑](https://img.lonelybing.top/file/post/动态.png)

- **🖼 相册 Gallery**：相册已经从配置文件迁移为内容集合，每个相册对应一个 `src/content/gallery/{id}.md` 文件，图片列表直接写在 frontmatter 的 `photos` 数组里，和文章/项目/动态一样规范。后台发布时直接写入这个 md 文件，同 id 覆盖、新 id 追加，相册批量添加图片也支持喵~

![相册编辑](https://img.lonelybing.top/file/post/相册.png)

## 四、安全：密码存在服务端

静态博客没有真正的"后端"，那登录怎么保证安全？答案是**把用户名和密码存在 Cloudflare Worker 的 Secrets 里**，前端永远拿不到凭据喵~

![登录界面](https://img.lonelybing.top/file/post/登录.png)

登录流程是这样的：

1. 输入用户名密码，先过 **Turnstile 人机验证**（防脚本爆破）
2. Worker 在服务端用常数时间比较校验凭据，还有同 IP 限流
3. 校验通过才签发一个 **12 小时有效的 HMAC 签名会话**，前端只存这个会话令牌
4. 每次进入后台都会重新校验会话签名和有效期，锁定即清除

也就是说，就算有人把后台页面的 JS 全部扒下来，也只能看到"去问服务端要会话"的逻辑，密码本身从头到尾不出现在前端喵~

## 五、发布 = 提交仓库

发布方式没有搞任何私有接口，就是**直接提交 GitHub 仓库**：

- 后台填好 GitHub 仓库信息和 Token
- 点发布，通过 GitHub API 把 Markdown 写进 `src/content` 对应目录
- 推送后 Cloudflare 自动触发构建，几分钟后文章就上线了

整条链路都是现成的基础设施，后台只是替你完成了"写文件 + 提交"这两步喵~

## 六、后续更新

上线后又陆续补了一堆功能和修复，一并记在这里喵~

### GitHub 仓库同步

后台新增了「仓库同步」功能，可以直接从 GitHub 拉取已有的文章、项目、动态、相册到本地在线编辑，改完点发布就会覆盖原文件——不用再克隆仓库、本地改、push 了，纯网页端就能完成全流程。

### 视频嵌入升级

视频嵌入弹窗重做了：

- **自动识别**：B 站支持 BV 号 / av 号 / 分P，YouTube 支持 `watch` / `youtu.be` / `shorts` / `embed` 各种链接格式，粘进去自动转成正确的 iframe
- **宽高可调**：可以手动设置宽度和高度（支持 `100%` / `640px`），默认适配容器
- **通用 iframe**：其他网站的视频只要是 `http(s)://` 链接也能嵌入，不局限于 B 站和 YouTube

### 表单折叠与必填标注

文章配置字段多的时候，左侧面板会按分类折叠成「基础信息」「封面图片」「标签与分类」「高级设置」「自定义字段」几组，点击标题即可展开/收起。每个字段还标注了必填（红色 `*`）和选填，一目了然喵~

### 体验修复

- **长文滚动**：编辑器加了 `min-height:0` 约束，长文章终于能正常鼠标滚轮滚动了
- **横向滚动**：编辑器和预览区都支持横向滚动——长行代码、宽表格不会被挤变形
- **撤销重做**：修复了工具栏撤销/重做按钮点击后焦点丢失导致无效的问题
- **关闭预览**：顶栏加了「预览」开关，可以隐藏预览面板给编辑器更多空间
- **移动端适配**：手机端也能正常使用后台，顶栏按钮可横滑、触摸目标放大、表单窄屏自动堆叠

### 相册迁移为内容集合

博客的相册从原来的 `galleryConfig.ts` + `public/gallery/{id}/urls.txt` 迁移为内容集合 `src/content/gallery/*.md`，和文章/项目/动态统一管理，更规范也更方便后台读写喵~
