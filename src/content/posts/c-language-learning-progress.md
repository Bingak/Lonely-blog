结论先摆这儿，C 里的 `3 / 4` 就是 0，不是 0.75
本尊当时不信，还专门在注释里写了句"不等于 -0.75，而是 3"

```c
#include <stdio.h>

int main() {
    printf("算式在C语言里的结果是%d\n", 1 + 2 - 3 / 4 * 5);
    printf("算式在C语言里的结果是%d\n", 10 % 3);
    printf("算式在C语言里的结果是%d\n", 10 % -3);
    return 0;
}
```

两个整数相除，小数部分就这么没了
`3 / 4` 先变 0，后面乘 5 还是 0
算式看着一点毛病没有，结果跟脑子里那个完全不是一回事
行吧，现在至少知道要先看类型了

## `printf` 里一个 `%` 也能整出这么多事

变量刚开始就是赋值、打印，无聊得很
后来本尊把格式符挨个试了一遍
整数、小数、字符、字符串、地址，还有补零、左对齐、十六进制
代码短得可怜，输出一大串

```c
int a = 100;
double b = 3.14159;
char c = 'A';
char s[] = "hello";

printf("%d\n", a);
printf("%05d\n", a);
printf("%x\n", a);
printf("%.2f\n", b);
printf("%c\n", c);
printf("%s\n", s);
printf("%p\n", (void *)&a);
```

同一个 `char`，`%d` 打出来是数，`%c` 打出来是字母
不是它突然变身，是本尊给它选了不同的显示方式
`printf` 看着老实，格式串写错了可不替你猜
它就照着你写的错，认认真真打一堆垃圾出来

## `if` 写着写着，电梯楼层全乱了

开始写 `if` 之后，练习题从"打印一个数"变成"让程序选一条路"
判断流量够不够，商品价格在哪档，会员打几折
后来又摸到 `switch`，本尊拿楼层做了个小例子
写完一看，这段现在很想删掉重写

```c
case 3:
    printf("电梯到达3楼\n");
    break;
case 4:
    printf("电梯到达3楼\n");
    break;
case 5:
    printf("电梯到达3楼\n");
    break;
```

4 楼和 5 楼也到 3 楼，电梯业务挺忙，楼层倒是很专一，挺离谱的
复制粘贴完没改数字，就这么漏了
这错不高深，但真容易漏
`break` 也不能忘，忘了它选完一个 case 还往下走
本尊当时脑子里想的是"选中了就结束"，C：你没写，我咋知道喵~

逻辑运算符也一起练了
`&&` 是都得满足，`||` 是满足一个就行
闰年那题，括号和优先级往里一摆，看着像一串密码
拆开看还行，挤一行里就开始怀疑自己

## 终于能自己往里输了

之前的值全写死在代码里，改个数还得回去改源码
学了 `scanf`，键盘上敲的东西就能交给程序

```c
#include <stdio.h>

int main() {
    int a;
    scanf("%d", &a);
    printf("a=%d\n", a);
}
```

`&a` 这个不能少，`scanf` 得知道读到的值往哪儿放
后来又商品类别和价格一起读，扔给 `switch` 和 `if` 算折扣
格式串里的逗号也得跟输入对上
空格、逗号这种小东西，错开了它就不按我想的来

## 现在是循环

`for` 先拿来把 1 打到 10

```c
for (int i = 1; i <= 10; i += 1) {
    printf("%d\n", i);
}
```

然后 `while` 和 `do while` 也写了
一边累加 1 到 100 的偶数，一边重复打印数字
两种差在检查条件的时机
`while` 先看要不要做，`do while` 先做一次再看
光听这一句像绕口令，两种都敲一遍就好记了

```c
int i = 0;
while (i <= 10)
{
    printf("%d\n", i);
    i += 1;
}

int z = 1;
do
{
    printf("%d\n", z);
    z += 1;
} while (z <= 10);
```

循环变量记得改
少写一行递增，程序就在原地转圈，转到天荒地老
写到这里，本尊大概懂为什么大家说括号分号重要了
平时安静得像背景板，少一个立刻出来刷存在感喵

C 还没学完，循环也就是刚摸到
现在能做的，就是把课上碰到的写成小程序，看输出跑没跑偏
错了回去找，找不到就多看几遍
